# 정비사업 입찰공고 수집기 - 사내 웹앱

기존 `collector_v2.py` 스크립트를 사내에서 여러 명이 브라우저로 같이 쓸 수 있도록
웹 화면(Streamlit)을 씌운 버전입니다. 핵심 수집/필터링/엑셀 생성 로직은 원본과 동일합니다.

## 폴더 구성

```
app/
  app.py              웹 화면 (Streamlit)
  collector_core.py   핵심 로직 (API 호출/필터링/분류/엑셀 생성)
  config.json         필터 키워드 설정 (웹 화면에서 편집하면 이 파일이 갱신됨)
  .env                SERVICE_KEY 등 비밀값 (직접 만들어야 함, git에 올리지 말 것)
  .env.example         .env 작성 예시
  requirements.txt    필요 패키지 목록
  logs/                실행 로그 (자동 생성)
  output/              결과 엑셀 / 첨부파일 다운로드 폴더 (자동 생성)
```

## 처음 설치 (사내 PC 한 대에서)

1. Python 3.9 이상이 설치되어 있어야 합니다.
2. 이 `app` 폴더를 사내에 항상 켜져 있는 PC(또는 서버)에 복사합니다.
3. 터미널(명령 프롬프트)에서:
   ```
   cd app
   pip install -r requirements.txt
   ```
4. `.env.example`을 복사해서 `.env`로 이름을 바꾸고, 공공데이터포털에서 발급받은
   `SERVICE_KEY` 값을 채워 넣습니다.
5. curl.exe를 이용한 회사망 우회가 필요한 환경이라면(원본 스크립트에서 이미
   확인하셨던 것처럼), 이 PC에도 curl이 PATH에 있어야 합니다. Windows 10/11은
   기본 내장되어 있어 별도 설치가 필요 없습니다.

## 실행

```
streamlit run app.py
```

실행하면 터미널에 다음과 같은 주소가 나타납니다.

```
Local URL: http://localhost:8501
Network URL: http://<이 PC의 사내 IP>:8501
```

- 이 PC에서 직접 보려면 `Local URL`을 브라우저에 입력합니다.
- **사내 다른 사람들이 접속하려면** `Network URL`(사내 IP 주소)을 알려주면 됩니다.
  같은 사내망(같은 와이파이/유선망) 안에서는 별도 설치 없이 브라우저만으로 접속됩니다.

## 화면 사용법

- **지금 수집하기** 버튼: 그 시점 기준으로 API를 조회해서 결과를 화면에 보여주고 엑셀로도 저장합니다.
- **왼쪽 사이드바 - 실행 옵션**: 조회 기간(직전 영업일만 / 최근 N일), 첨부파일 다운로드 여부를 그때그때 바꿀 수 있습니다.
- **왼쪽 사이드바 - 필터 규칙 편집**: 발주기관/공고명 포함·제외 키워드를 코드 수정 없이 텍스트로 바로 고칠 수 있습니다.
  "필터 규칙 저장"을 누르면 `config.json`에 반영되고, 다음 실행부터 바로 적용됩니다.
- **엑셀 다운로드 버튼**: 결과가 나오면 원본과 동일한 서식의 엑셀 파일을 다운로드할 수 있습니다.
- **실행 로그**: 그 실행에서 무슨 일이 있었는지(재시도, 실패한 첨부파일 등)를 실시간으로 보여주고,
  `logs/collector_YYYYMMDD.log` 파일에도 그대로 남습니다.

## 매일 자동 실행이 필요하면

지금은 사람이 버튼을 눌러야 실행되는 구조입니다. 매일 아침 자동으로 돌리고 싶다면
`collector_core.run_pipeline()`을 호출하는 간단한 스크립트를 하나 더 만들어서
Windows 작업 스케줄러(또는 cron)에 등록하면 됩니다. 이 부분은 원하시면 이어서 만들어드릴게요.

## 원본과 달라진 점 (요약)

| 항목 | 원본 collector_v2.py | 이번 버전 |
|---|---|---|
| SERVICE_KEY | 코드에 하드코딩 | `.env` 파일로 분리 |
| 필터 키워드 | 코드 상수 | `config.json` + 웹 화면 편집 |
| API 실패 시 | 그냥 건너뜀 | 지수 백오프로 재시도 |
| 실행 결과 확인 | 콘솔 print | 웹 화면 + 로그 파일 |
| 실행 방식 | 터미널에서 직접 실행 | 브라우저에서 버튼 클릭 (누구나) |
| 핵심 로직 | - | **완전히 동일** (필터링/분류/엑셀 서식 모두 그대로) |
